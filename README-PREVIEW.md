# 沙雕园

网站：<https://blog.shadiao.win/>。

**这台电脑：双击桌面“写博客”。** 固定源码目录是桌面的 `blog`，不再使用日期任务目录作为日常入口。

菜单支持新建长文章、短动态、打开稿件、本地预览、同步和发布。发布先检查，输入“发布”才上传当前选中的稿件及图片；不会夹带其他草稿。

完整的简短说明：[PUBLISHING.md](PUBLISHING.md)。其他电脑克隆本仓库并完成 `setup` 后，可直接双击 `write-blog.cmd`。

项目沿用 Markdown、Hugo 和 GitHub Pages，已保留原文章、图片和历史链接。`public` 是独立的网页产物仓库，日常写作请操作 `content/zh-CN/post` 或 `content/zh-CN/moments`。
